## 写作要求

| 要求 | 说明 |
|---|---|
| 目标必须可量化 | "改善体验"不合格；"诊断耗时 < 300 ms" 合格 |
| 必须写非目标 | 否则执行中会不断加需求 |
| 必须有备选路线 | 否则无法判断当前选择是否合理 |
| **必须指明验证级别** | L1 能覆盖的不要拖到 L4 手点 |
| 必须写降级行为 | 依赖缺失时是报错、是静默、还是明确提示？ |
| 必须写回退方案 | 新功能要能一键关掉 |
