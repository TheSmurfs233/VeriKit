## 写作要求

| 要求 | 说明 |
|---|---|
| 职责必须写"不负责什么" | 防止后续把所有东西都塞进来 |
| **必须标明是否 import vscode** | 决定了它能不能被单测覆盖 |
| 时序必须写实测耗时 | 决定能否放进文档事件回调（会阻塞输入） |
| 必须写竞态保护方式 | 异步 + 文档事件 = 一定有竞态 |
| "坑"章节必须持续更新 | 否则文档只有"介绍"没有"经验" |
| 接口表要写调用上下文 | 避免在错误的地方调用（在同步路径里做长任务） |
