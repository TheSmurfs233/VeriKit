> 唯一规则：**追加，不修改旧条目**。

---

## 写作要求速查

| 要求 | 说明 |
|---|---|
| 必须有数据 | 没有数据的条目 = 日记，不是日志 |
| 数值必须带单位 | `92 ms` / `23 条` / `248 行`，不要写裸数字 |
| 保留原始日志片段 | 便于事后重新分析（不要"整理"掉细节） |
| 记录偶发问题 | 偶发问题最值钱（"必现"的问题很快会被修掉） |
| 记录被推翻的假设 | 这是最高价值的知识 |
| 附版本 build 号 | 否则无法追溯"是哪个产物测出来的" |
| 记录环境 | OS / VSCode 版本 / 工具链版本，换机器结论可能就变了 |
